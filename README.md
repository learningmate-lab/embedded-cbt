# 임베디드 CBT

차량용 임베디드 시스템 프로그래밍(NXP S32K312, 1~6장) 시험 대비 문제은행(268문항)이에요.

- **개념 정리**: 1~6장 개념 카드 67개 + 레지스터 비트·타이밍·구조 그림. 문제 해설에서 "관련 개념"으로, 개념 카드에서 "이 주제 문제 풀기"로 이어져요
- **문제 형식**: 객관식 · 결과 + 원인("이 코드 실행하면? 왜?") · 단답형, 유형은 코드 읽기 · 오류 판단 · API·설정 · 계산 · 개념
- **실전 모의고사**: 25문항(장마다 4~5문항, 유형 섞어서), 검토 표시, 제출 전 전체 검토, 장별·유형별 점수
- **연습 모드 / 오답노트**: 장 · 유형 · 형식 · 난이도 필터, 보기마다 맞고 틀린 이유 해설

사이트: https://learningmate-lab.github.io/embedded-cbt/

문제는 수업 자료를 바탕으로 새로 쓴 연습 문제예요.
