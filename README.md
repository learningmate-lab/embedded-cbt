# 임베디드 랩

차량용 임베디드 시스템 프로그래밍(NXP S32K312, 1~6장) 시험 대비 연습 사이트예요.

- **보드**: S32K312 칩과 장별 주변장치(UART · GPIO · IPL/MCAL · I2C LCD · 인터럽트 · ADC)를 기판처럼 보여 주고, 장마다 정답률을 LED 색으로 표시해요
- **문제 268개**: 코드 편집기 모양으로 읽는 코드 문제, 결과 + 원인("이 코드 실행하면? 왜?") 2단계, 단답형. 연습할 때는 옆에 C 정수식 계산기가 열려요
- **실습 도구 7개**: 비트 연산기 · SIUL2 주소 계산기(MSCR · GPDO 역순) · UART 8N1 프레임 · I2C/PCF8574 바이트 · 인터럽트 번호 · ADC/이동 평균 · IPL ↔ MCAL 짝 맞히기
- **개념 카드 67개**: 레지스터 비트 · 타이밍 · 구조 그림 포함
- **모의고사 25문항**: 장 순서대로, 계산기 없이. 결과는 장별 · 유형별 PASS/FAIL 로그로

사이트: https://learningmate-lab.github.io/embedded-cbt/

문제와 도구는 수업 자료를 바탕으로 새로 만든 연습 자료예요.
